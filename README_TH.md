# NCD Care Frontend — Phase 2 (Login + App Shell)

## ติดตั้งบน GitHub Pages (แนะนำให้ลองในโฟลเดอร์ใหม่ก่อน เทียบกับของเดิมได้)
1. ในรีโป GitHub เดิม สร้างโฟลเดอร์ `v2/` แล้วอัปโหลดไฟล์ทั้งหมดในนี้ (index.html, css/, js/, assets/)
2. Settings → Pages → ใช้ branch เดิม → เปิด `https://<ชื่อคุณ>.github.io/<รีโป>/v2/`
3. Backend ต้อง Deploy `Code_Phase1.gs` เป็น New version แล้ว (ใช้ URL /exec เดิม ซึ่งใส่ไว้ใน `js/api.js` ให้แล้ว)

## โครงสร้าง
- `css/theme.css` — ธีมสว่างโทนเขียว, ฟอนต์ Sarabun, ไล่สีแบบเรียบ เงาเบาเฉพาะกล่อง (ปรับสีที่ตัวแปรบนสุด `:root`)
- `js/api.js` — เชื่อม Backend: timeout 25 วิ, retry เฉพาะการอ่าน, ข้อความ error ภาษาไทย
- `js/app.js` — Login, หน้าแรก, รายชื่อ, ติดตาม, ส่งต่อ (อ่านอย่างเดียว)
- `assets/` — โลโก้ รพ. ที่บีบแล้ว (96px = 3 KB, 192px = 7 KB)

## การแสดงผล
- หน้าจอกว้าง ≥ 900px (คอมพิวเตอร์/แท็บเล็ตแนวนอน): เมนู **Sidebar ด้านซ้าย** ทั้ง อสม. และ Admin
- หน้าจอเล็ก (มือถือ): เมนู **แถบล่าง** (ปรับจุดตัดที่ `@media (min-width:900px)` ท้ายไฟล์ `css/theme.css`)

## หมายเหตุ
- เปิดแอป = เรียก Backend 1 ครั้ง (`home`) และจำข้อมูลล่าสุดไว้ในเครื่องเพื่อแสดงทันที ข้อมูลนี้ถูกลบเมื่อออกจากระบบหรือเซสชันหมดอายุ
- Admin ล็อกอินได้ แต่ Dashboard อยู่ Phase 4 (ระหว่างนี้ใช้ระบบเดิม)
- ฟอร์มคัดกรอง/บันทึกติดตาม/ส่งต่อ ยังไม่อยู่ในเวอร์ชันนี้ (Phase 3)
