# NCD Care โรงพยาบาลศรีสาคร (Frontend PWA)

## ทดลองดูแบบไม่ต้องต่อระบบจริง
เปิด `index.html#/login?demo` ผ่านเว็บเซิร์ฟเวอร์ (เช่น `python3 -m http.server`) จะใช้ข้อมูลสมมติ
- โหมดสาธิตจะกรอกข้อมูลตัวอย่างให้ในหน้า Login อัตโนมัติ (ไม่เชื่อมฐานข้อมูลจริง)

## ขึ้น GitHub Pages
1. สร้าง repo แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ราก
2. Settings > Pages > Deploy from branch > main / root
3. แก้ `js/config.js` ใส่ `API_URL` ของ Apps Script (ลงท้าย /exec) และตั้ง `DEMO:false`
4. เปิดบนมือถือ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" จะใช้งานเหมือนแอป

## หมายเหตุ
- ใช้ API เดิมของ Apps Script โดยไม่เปลี่ยนชื่อชีตหรือฟิลด์
- ถ้าแก้ไฟล์ในแอป ให้เปลี่ยนเลขเวอร์ชันแคชใน `sw.js` (ปัจจุบัน ncd-care-v2)
- ยังไม่ควรเปิดสาธารณะจนกว่าจะเปลี่ยนการล็อกอินของ อสม. จากเลขบัตรอย่างเดียวเป็นมี PIN

- หน้าแรกของ อสม. เรียก Backend ครั้งเดียว (endpoint `home`) ต้อง Deploy Code_Phase1.gs ขึ้นไปก่อน
- ก่อนเปิดใช้จริง ต้องปิดบัญชีทดสอบ (TEST001) ในชีต Volunteers

## แผนที่พื้นที่ (Admin)
- ขอบเขตหมู่บ้านอยู่ใน `js/areageo.js` (สร้างจากไฟล์ KMZ ของ Google My Maps: ncd_care_v2.kmz) ถ้าวาดขอบเขตใหม่ ส่งไฟล์ KMZ ใหม่มาให้สร้างไฟล์นี้ใหม่
- แสดงที่ "ภาพรวม" และบนสุดของหน้า "พื้นที่" · สลับ แผนผัง/แผนที่จริง (OpenStreetMap ต้องต่ออินเทอร์เน็ต) · สลับตัวชี้วัดได้ 4 แบบ
- ต้องใช้ Backend เวอร์ชัน 2.3 ขึ้นไป (`Code_v23.gs`) เพื่อให้ได้ผล HT/DM และงานติดตามรายหมู่ ถ้าใช้ Backend เก่าจะแสดงเฉพาะความครอบคลุม
- ดูตัวอย่างโดยไม่ต้องต่อฐานข้อมูล: เปิด `.../ncd-care-app/?demo`
